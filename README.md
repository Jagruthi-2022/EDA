# Exploratory Data Analysis (EDA) Projects

## Overview

This repository contains exploratory data analysis (EDA) projects performed on two popular datasets:

1. **Titanic Dataset**
2. **Iris Dataset**

The objective of these projects is to understand the datasets through data cleaning, visualization, statistical analysis, and feature exploration.

---

# 1. Titanic Dataset EDA

## Objective

The Titanic dataset is a classic machine learning dataset used to analyze passenger information and predict survival outcomes.

## Analysis Performed

* Dataset exploration and understanding
* Missing value analysis
* Data cleaning and preprocessing
* Survival distribution analysis
* Gender-wise survival comparison
* Passenger class analysis
* Age distribution analysis
* Correlation analysis
* Data visualization using charts and plots

## Key Insights

* Female passengers had significantly higher survival rates.
* First-class passengers were more likely to survive than passengers in lower classes.
* Age and passenger class influenced survival probability.
* Missing values required preprocessing before further analysis.

---

# 2. Iris Dataset EDA

## Objective

The Iris dataset is one of the most widely used datasets for understanding classification problems in machine learning.

## Analysis Performed

* Dataset exploration and summary statistics
* Missing value inspection
* Feature distribution analysis
* Species-wise comparison
* Correlation analysis
* Pair plots and scatter plots
* Box plots and histograms
* Feature relationship visualization

## Key Insights

* Petal length and petal width are highly informative features for species classification.
* Iris-setosa is clearly separable from the other species.
* Strong correlations exist between several flower measurements.
* Visualizations reveal distinct patterns among species groups.
